# pdf

## Purpose
Render a completed report into a downloadable PDF artifact.

## Required behavior
- Preserve the report structure from the markdown source.
- Render headings, paragraphs, and bullets legibly.
- Use sane page margins and automatic pagination.
- Keep the PDF artifact in the session output folder.

## Constraints
- Do not add unrelated content to the report.
- Do not treat the PDF as optional for report jobs.
